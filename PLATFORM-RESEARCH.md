# Platform research: Squarespace

## Status
Guide-only workspace. Squarespace says its Commerce API cannot connect third-party processors, so a normal WiPay checkout plugin is not currently a documented option.

## Possible guide
Document an off-platform/manual payment-link workflow only if WiPay confirms suitable merchant links/invoices and the merchant accepts manual payment matching. Do not promise automatic Squarespace order confirmation, synchronization, or refunds.

## Next decisions

- Re-check Squarespace's official processor limitations before publishing.
